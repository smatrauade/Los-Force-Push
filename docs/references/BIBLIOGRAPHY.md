# Bibliografía conceptual

Estas obras sirven de referencias conceptuales para explicar las responsabilidades y los patrones del diseño. El repositorio no redistribuye libros ni materiales completos de cátedra, ni atribuye citas textuales sin localización.

| Referencia | Relación con el proyecto |
|---|---|
| Craig Larman, *UML y Patrones*, 2.ª edición | GRASP: Information Expert, Controller, bajo acoplamiento y alta cohesión |
| Rebecca Wirfs-Brock y Alan McKean, *Object Design: Roles, Responsibilities, and Collaborations* | Asignación de roles y límites entre motor, sesión, parser y vista |
| Erich Gamma, Richard Helm, Ralph Johnson y John Vlissides, *Design Patterns: Elements of Reusable Object-Oriented Software* | Intención, participantes y consecuencias de Abstract Factory, Command y Observer |
| Grady Booch, James Rumbaugh e Ivar Jacobson, *The UML Reference Manual* | Asociaciones, composición, interfaces y multiplicidades |

La fuente académica principal es la consigna del Trabajo Integrador de Procesos de Desarrollo de Software, UADE, docente Jonathan Leonel Pepe. Sus requisitos se sintetizan en [REQUIREMENTS](../requirements/REQUIREMENTS.md). Las [decisiones del proyecto](../decisions/DECISION_LOG.md) relacionan los conceptos con clases reales; no se trasladan requisitos o código desde otros juegos.
